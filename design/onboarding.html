Mull
1.

A thinking layer for your Mac

Hold ⌥ Space in any app — Mail, Notes, your editor — and speak. Mull turns your words into clean text, placed exactly where your cursor is. Ask for changes, and it shows every mark before anything lands.

✓ On-device. Your voice is transcribed on this Mac and discarded. Nothing is uploaded.
✎ Nothing changes without a preview. Edits appear as editor's marks you approve — or don't.
⌥Z Everything is undoable. Every action lands in a journal, and ⌥ Z takes it back.

3.

Three permissions, each with a reason

macOS will ask you to grant these. Mull asks for nothing it can’t explain — and works with whatever you grant.

· Microphone To hear you. Audio becomes text on this Mac, then is discarded.
· Accessibility To place text at your cursor and read what you’ve selected.
· Input Monitoring To notice ⌥ Space even while Mull is in the background.
Secure input — paused In password fields, macOS blocks listening tools — Mull pauses itself and says so, right in the HUD.
4.

Your ears, kept local

Mull listens with a speech model that runs entirely on this Mac. One download, then it works everywhere — on planes, on VPNs, offline.

· Whisper — English + multilingual ≈500 MB · saved to Application Support, removable anytime 0%—
Because the model is local, the transcript never crosses the network — the privacy claim on page 1 is architecture, not policy.

Design notes

page 1 The HUD appears before it's explained. The idle panel sits on the welcome page as an object, not a screenshot — the user meets the instrument at rest, ghost hint and all.
page 2 The trust story is the demo. Instead of describing previews, the page hands over a live diff card with the brief's canonical sample. Apply works; the undo promise is printed in the same breath (§7.2).
page 3 Permissions use the plan-card grammar. Each grant is a step row with the ·/…/✓ state cells from §6.4 — the same visual language the app will use for command plans, learned here for free. Every permission states its reason; the secure-input pause is disclosed up front.
page 4 Privacy as architecture. The model download is the proof of the on-device claim, so the page says so. Progress is mono, tabular, honest.
page 5 Rehearsal, not tour. The last page is a sandbox: hold, speak, watch the state run idle → listening → thinking → applied, see text land at a caret, see the journal ghost with ⌥ Z. The user leaves having done the core loop once.
window Numbered manuscript. One step per serif-numbered page (§6.8), progress as quiet ink ticks. Sans = instrument voice for all labels; serif is reserved for headings and anything spoken.
